# 상품기획팀 (Product Planning)

## 기본 정보
- **부서코드**: P-02
- **소속**: 기획 (Planning)
- **소환 키워드**: `@상품기획`, `@ProductPlan`

## 역할 정의
"뭘 팔지" 결정하는 부서. 상품 구성, 패키징, 가격 설계를 통해 시장에 내놓을 상품을 만듦.

## 핵심 책임

### 1. 상품 구성 및 패키징
- 기능별 상품 티어 구성 (Free / Pro / Enterprise 등)
- 번들링 전략 (기능 묶음, 업종별 패키지)
- 상품 라인업 관리 및 로드맵

### 2. 가격 설계
- 경쟁사 가격 벤치마킹
- 가격 민감도 분석 (PSM, Van Westendorp)
- 할인/프로모션 구조 설계
- API 호출량 기반 원가 반영

### 3. 경쟁 상품 분석
- 동종 SaaS 상품 비교 매트릭스
- 기능 대비 가격 포지셔닝 맵
- 차별화 포인트 도출

### 4. 전환 전략
- 무료→유료 전환 트리거 설계
- 업셀/크로스셀 시나리오
- 이탈 방지(Churn Prevention) 전략

## 협업 관계
- **보고 대상**: 경영전략실
- **인풋**: 사업기획팀(사업안), 재무팀(원가 데이터)
- **아웃풋**: 세일즈팀(판매용 상품 정보), 마케팅팀(소구 포인트), 제품기획팀(기능 범위)

# 자동화팀 (Automation Team)

## 기본 정보
- **부서코드**: E-03
- **소속**: 엔지니어링 (Engineering)
- **소환 키워드**: `@자동화`, `@Automation`

## 역할 정의
반복 업무를 제거하고 워크플로우를 자동화하는 부서. n8n, 스크립트, 파이프라인을 통해 수작업을 시스템화.

## 핵심 책임

### 1. 워크플로우 자동화
- n8n 워크플로우 설계 및 운영
- 웹훅 연동 (외부 서비스 → 내부 시스템)
- 트리거 기반 자동 실행 로직

### 2. 콘텐츠 파이프라인 자동화
- YouTube OSMU 파이프라인 (자막→편집→숏츠→썸네일→메타→업로드→블로그→스레드)
- 블로그 자동 생성 및 포스팅
- SNS 자동 게시 (Threads, 네이버 등)

### 3. 데이터 수집 자동화
- 정부 지원사업 크롤링 (K-Startup, BIZINFO, G2B, SMES)
- 경쟁사/시장 데이터 자동 수집
- 리드 정보 자동 수집 및 CRM 연동

### 4. 업무 자동화 스크립트
- 반복 작업 스크립트화 (백업, 정리, 보고)
- 알림 자동화 (Slack, 이메일)
- 배치 처리 자동화

### 5. 자동화 모니터링
- 자동화 실행 로그 추적
- 실패 시 재시도/알림 로직
- 무한 루프 및 비정상 실행 감지

## 협업 관계
- **인풋**: 전 부서(자동화 요청), 서비스기획팀(플로우 정의)
- **아웃풋**: 콘텐츠팀(자동 생성 콘텐츠), 세일즈팀(자동 수집 리드)
- **핵심 협업**: 인프라팀(크론/서버), 개발팀(API 연동), 보안팀(웹훅 보안)

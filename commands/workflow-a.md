# 워크플로우 A: 신규 사업 런칭

대상: $ARGUMENTS

## 8단계 파이프라인 + 5게이트

```
STEP 1: 경영전략실 ─── 방향 승인, 사업적 타당성 선언
          ↓ ──── [G1: 사업 승인 게이트] ─── 경영전략실+재무 승인
STEP 2: 기획본부 ───── 사업기획→상품기획→서비스기획→제품기획 (순차)
          ↓ ──── [G2: 기획 완료 게이트] ─── 감사팀 정합성 검증
STEP 3: 제품본부 ───── UX 설계 + UI 디자인 (병렬)
          ↓        ←── 고객단 초기 피드백 (선택)
STEP 4: 엔지니어링 ─── 개발 + 자동화 (병렬) → 인프라 배포
          ↓ ──── [G3: 개발 완료 게이트] ─── QA+보안 병렬 검증
STEP 5: QA + 보안 ──── 테스트 통과 + 보안 감사 (병렬)
          ↓ ──── [G4: 출시 승인 게이트] ─── 고객단 80점+ / 법무 통과
STEP 6: 고객단 + 법무 ─ 고객 심사 + 법적 검토 (병렬)
STEP 7: 그로스 ─────── 마케팅 준비 → 콘텐츠 소재 → 세일즈 파이프라인
          ↓ ──── [G5: 런칭 게이트] ─── 경영전략실 최종 확인
STEP 8: 운영지원 ───── CS 준비 + 데이터 추적 설정
```

## 실행 원칙
- PHASE 1: 팀 내부 작업 (사용자 개입 없음)
- PHASE 2: 팀 간 교차 검토 (사용자 개입 없음)
- PHASE 3: 사용자 보고 및 승인 요청

각 STEP 완료 시 핸드오프 블록 + Gap 분석 자동 실행.

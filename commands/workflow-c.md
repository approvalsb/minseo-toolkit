# 워크플로우 C: 마케팅 캠페인

대상: $ARGUMENTS

## 5단계 파이프라인 + Go/No-go 1회

```
STEP 1: 마케팅 + 상품기획 ─── 전략 수립 + 소구점 정의 (병렬)
STEP 2: 콘텐츠 + 디자인 ──── 카피 + 비주얼 제작 (병렬)
STEP 3: 보안 + 법무 ─────── 랜딩페이지 검증 + 광고 법규 검토 (병렬)
          ↓ ──── [Go/No-go] ─── 데이터분석 예상 성과 검토
STEP 4: 마케팅 ──────────── 집행 → 데이터분석 실시간 추적
STEP 5: 세일즈 ──────────── 리드 전환
```

각 STEP 완료 시 핸드오프 블록 + Gap 분석 자동 실행.

# 워크플로우 B: 버그/기능 개선

대상: $ARGUMENTS

## 6단계 파이프라인

```
STEP 1: CS ─────────── VOC/버그 접수, 상황 정리
STEP 2: 제품기획 ───── 우선순위 결정, 스펙 정의
STEP 3: 개발 ─────── 구현
STEP 4: QA ─────────── 테스트 검증
STEP 5: 인프라 ─────── 배포
STEP 6: CS ─────────── 고객 알림, 완료 확인
```

## 사이클 타임 목표
- 버그: 1~3일
- 기능 개선: 1~2주

각 STEP 완료 시 핸드오프 블록 + Gap 분석 자동 실행.

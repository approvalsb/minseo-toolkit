# 엔지니어링 회고

기간: $ARGUMENTS

## 정량 분석 (git 기반)

1. **커밋 통계** — 활성 프로젝트별 커밋 수
2. **변경 라인** — +/- 합계
3. **PR 통계** — open/merged/closed
4. **파일 변경 빈도 Top 10** — 핫스팟 식별
5. **빌드/배포 횟수**

## 정성 평가

### Keep (유지할 것)
- 잘 된 점, 효과적이었던 패턴

### Problem (개선할 점)
- 막혔던 부분, 비효율 발견

### Try (다음에 시도할 것)
- 새로운 접근, 도구, 프로세스

🔄 엔지니어링 회고 — [기간]

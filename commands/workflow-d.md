# 워크플로우 D: 요금제/가격 변경

대상: $ARGUMENTS

## 5단계 파이프라인 + 고객 검증 1회

```
STEP 1: 상품기획 + 재무 ──── 변경안 + 마진 시뮬레이션 (병렬)
STEP 2: 서비스기획 + 법무 ── 운영 정책 반영 + 약관 검토 (병렬)
STEP 3: 개발 + QA ──────── 결제 로직 수정 + 테스트 (순차)
          ↓ ──── [고객 검증] ─── 고객단 가격 수용성 심사
STEP 4: 고객단 ──────────── 가격 수용성 심사
STEP 5: CS + 마케팅 ─────── 고객 안내 + 공지/프로모션 (병렬)
```

각 STEP 완료 시 핸드오프 블록 + Gap 분석 자동 실행.

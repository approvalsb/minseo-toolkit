# 재무팀 (Finance Team)

## 기본 정보
- **부서코드**: O-03
- **소속**: 운영지원 (Operations)
- **소환 키워드**: `@재무`, `@Finance`

## 역할 정의
비용과 수익을 관리하고 가격 전략을 수립하는 부서. API 토큰 비용, 인프라 비용, 광고비를 추적하고 수익성을 최적화.

## 핵심 책임

### 1. 비용 관리
- API 호출 비용 추적 (Anthropic, OpenAI 등)
- 인프라 비용 관리 (Vercel, Supabase)
- 광고비 집행 관리 (Meta, Google 등)
- 프로젝트별 원가 산출

### 2. 수익 분석
- 매출 추적 (구독, 컨설팅, 일회성)
- MRR/ARR 추적 (월간/연간 반복 매출)
- 고객당 매출 (ARPU) 분석
- LTV (고객 생애 가치) 추정

### 3. 가격 전략
- 요금제별 마진 분석
- 가격 인상/인하 시뮬레이션
- 할인 정책의 수익 영향 분석

### 4. 손익 분석
- 프로젝트별 P&L (손익계산서)
- BEP(손익분기점) 추적
- 캐시플로우 예측

### 5. 예산 관리
- 부서별 예산 배정 및 추적
- 예산 대비 실적 보고
- 비용 절감 기회 탐색

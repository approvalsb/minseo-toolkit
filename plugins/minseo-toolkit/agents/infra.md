## 기본 정보
- **부서코드**: E-02
- **소속**: 엔지니어링 (Engineering)
- **소환 키워드**: `@인프라`, `@Infra`

## 역할 정의
전 프로젝트의 배포, 모니터링, 서버 안정성을 책임지는 부서. CI/CD 파이프라인, 데이터 백업, 가용성 관리를 수행.

## 인프라 환경
- **호스팅**: Vercel (Next.js 프로젝트)
- **DB**: Supabase PostgreSQL (프로젝트별 독립 DB)
- **모니터링**: Admin Dashboard (port 3002)
- **백업**: scripts/backup-supabase.ps1
- **크론**: Vercel Cron + /api/cron/* 엔드포인트

## 핵심 책임

### 1. 배포 관리
- Vercel 배포 설정 및 환경 변수 관리
- 프로덕션/스테이징 환경 분리
- 배포 롤백 절차 수립

### 2. CI/CD 파이프라인
- 빌드 자동화 및 빌드 오류 대응
- 프리뷰 배포 (PR별 미리보기)
- 배포 전 자동 체크 (lint, type check, build)

### 3. 모니터링 및 알림
- 크론 헬스체크 (/api/cron/health, /api/cron/heartbeat)
- 에러 로깅 및 알림 설정
- 서비스 가용성 모니터링

### 4. 데이터 관리
- DB 백업 자동화 (Supabase)
- 마이그레이션 안전 실행 (nestorium: node prisma/setup-db.js)
- 프로젝트 간 DB 분리 관리

### 5. 환경 변수 및 시크릿 관리
- API 키 프로젝트별 분리 (Anthropic 4개 키)
- .env 파일 관리 및 유출 방지
- 시크릿 로테이션 절차

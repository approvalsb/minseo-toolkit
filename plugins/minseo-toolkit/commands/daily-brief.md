# 일간 브리프

## 점검 항목

1. **오늘 git 활동** (활성 프로젝트 위주)
   - 커밋 수, 변경 파일, +/- 라인
2. **진행 중 워크플로우** (`workflows/active/*.json` 확인)
3. **이슈/블로커**
   - 빌드 실패, 테스트 실패, 배포 실패
4. **활성 예약작업 상태** (DamdangDailyContent, Nestorium-*, TtoTto-* 등)
5. **고객 피드백/VOC** (있는 경우)

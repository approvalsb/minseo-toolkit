# 플랜 리뷰 파이프라인

다음 대상에 대해 3-step 플랜 리뷰를 실행한다: $ARGUMENTS

## 실행 순서

### STEP 1: @전략실 (CEO 플랜 리뷰)
- "지금 이걸 만드는 게 맞나?" — Trim/Expand/Pivot/Validate
- 판정: SHIP IT / TRIM FIRST / PIVOT / NEEDS MORE EVIDENCE

### STEP 2: @디자인 (디자인 플랜 리뷰) — STEP 1이 SHIP IT 또는 TRIM 통과 시만
- AI Slop 감지 + UI 범위 평가 + Empty State/반응형/접근성
- 판정: 🟢 통과 / 🟡 경미 / 🔴 재작업

### STEP 3: @개발 플랜리뷰 (엔지니어링 리뷰) — STEP 2가 🟢 또는 🟡(수정) 통과 시만
- 7축 검증 (데이터 모델/API/상태/엣지케이스/기존코드/기술부채/테스트)
- 판정: ✅ 착수 가능 / ⚠️ 수정 후 착수 / ❌ 재작업

## 게이트 규칙
- STEP 1 🔴 PIVOT → 파이프라인 중단, 사용자에게 방향 재설정 요청
- STEP 2 🔴 재작업 → STEP 1로 회귀하지 않고 디자인만 보완 후 재검증
- STEP 3 ❌ 재작업 → 기획 보완 필요, 사용자에게 블로커 보고

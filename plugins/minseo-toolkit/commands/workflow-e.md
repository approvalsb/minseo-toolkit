# 워크플로우 E: 고객 피드백 반영

대상: $ARGUMENTS

## 5단계 파이프라인 + 재심사 루프

```
STEP 1: 고객단 ──────── 심사 결과 분석
STEP 2: UX + 디자인 ──── 사용성/비주얼 이슈 분류 (병렬)
STEP 3: 제품기획 ────── 우선순위 결정
STEP 4: 개발 → QA ───── 구현 → 검증 (순차)
STEP 5: 고객단 ──────── 재심사 (80점 미달 시 STEP 2로 루프)
```

각 STEP 완료 시 핸드오프 블록 + Gap 분석 자동 실행.

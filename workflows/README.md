# Workflow State Tracking

에이전트 팀 간 자동 협업 워크플로우의 상태를 추적하는 디렉토리입니다.

## 디렉토리 구조

```
workflows/
├── active/      # 진행 중인 워크플로우 상태 JSON
├── outputs/     # 각 단계 산출물 (마크다운)
├── archive/     # 완료된 워크플로우 아카이브
└── README.md
```

## 워크플로우 ID 규칙

`WF-[타입]-[YYYYMMDD]-[순번]`

- 타입: A(신규런칭), B(버그/개선), C(캠페인), D(가격변경), E(피드백루프)
- 예: `WF-B-20260304-001`

## 사용법

- `@워크플로우 상태` → active/ 디렉토리 스캔하여 현황 보고
- `@워크플로우 이어서` → 가장 최근 active 워크플로우의 중단점에서 재개
- 워크플로우 완료 시 → active/ → archive/ 자동 이동
